# 老人桌面助手

这是一个纯原生 Android 小工具应用，面向小米/MIUI/HyperOS 桌面使用：

- 列出手机里可启动的应用。
- 给某个应用添加大尺寸桌面入口，尺寸支持 1x1 到 4x4。
- 桌面入口可使用应用默认图标，也可选择自己的图片。
- 提供“大电量”和“大钟表”两个桌面小组件。

## 构建 APK

本仓库不提交 Gradle Wrapper，也不要求本地下载依赖。把代码推到 GitHub 后：

1. 打开仓库的 `Actions` 页面。
2. 运行或等待 `Android Debug APK` 工作流完成。
3. 在工作流结果的 `Artifacts` 里下载 `elder-home-helper-debug.apk`。
4. 把 APK 安装到手机上测试。

如果桌面没有弹出“添加到桌面”的确认窗口，请长按桌面，进入小部件，选择对应尺寸的“大应用入口”。
